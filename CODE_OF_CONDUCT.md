# Code of Conduct

This project follows the Contributor Covenant, version 2.1.

The short version: be kind, be professional, assume good faith.
Harassment, personal attacks, and publishing private information are
not acceptable. Maintainers may remove contributions and ban
participants who violate this.

Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Report incidents to the maintainer via the contact listed on the
repository profile.
